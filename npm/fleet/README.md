# @zzacong/fleet

Fleet manages agent skills across AI coding agents — opencode, pi, codex, claude code, IBM Bob, and Cursor. Turn a skill off for one harness without uninstalling it. This package runs the prebuilt `fleet` binary for your OS and arch (no build step, no Go toolchain).

## Quick start

```sh
npx -y @zzacong/fleet --version
```

```sh
curl -fsSL https://raw.githubusercontent.com/zzacong/fleet/main/install.sh | sh
```

Every install method (script, `npx`/`pnpm dlx`/`bunx`, global installs, `go install`), with pin and override variants, lives on the [Installation page](https://fleet.zzacong.com/installation/).
