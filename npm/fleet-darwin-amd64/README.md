# @zzacong/fleet-darwin-amd64

Prebuilt `fleet` binary for macOS on Intel. You almost never install this directly — install [@zzacong/fleet](https://www.npmjs.com/package/@zzacong/fleet) instead, which pulls in the right platform package for your machine automatically.

Full docs and source: [github.com/zzacong/fleet](https://github.com/zzacong/fleet).
